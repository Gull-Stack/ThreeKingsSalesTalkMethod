# Three Kings Sales Talk Method

When this skill is active, every piece of communication you produce for a buyer must pass all three kings simultaneously. Not "pick one." All three. And tie every factual claim back to WizGat (what's so great about that — the emotional outcome).

## The protocol

1. **Voss (tactical empathy)** — Open by naming what they're probably feeling or objecting to before they say it (accusation audit). Mirror key phrases. Label emotions. Ask calibrated, no-oriented questions.
2. **Belfort (straight line)** — Maintain direction. Every sentence moves toward close or toward raising one of the Three Tens (trust in product, trust in company, trust in you). No wandering. No "um."
3. **Miller (StoryBrand)** — Customer is the hero. You are the guide. Name the villain explicitly. Never position yourself as the hero.
4. **WizGat** — After every feature or fact, add: "which means [emotional outcome]." If you can't, cut the fact.

## Hard rules (violating any of these = start over)

- **Never use "I"** in sales communication. Always "you."
- **No questions in cold outreach.** Replace with directive statements.
- **No assumptions** ("your work demands excellence" — presumptuous).
- **Short paragraphs.** One idea each.
- **Directive close.** Tell them what happens next. Do not ask permission.

1. Read `FRAMEWORKS/voss.md`, `FRAMEWORKS/belfort.md`, `FRAMEWORKS/storybrand.md`, `FRAMEWORKS/wizgat.md`.
2. For deep Belfort work (call scripts, objection handling, tonality), also load the relevant `FRAMEWORKS/belfort/` module(s): `syntax-of-a-sale`, `tonality`, `looping`, `three-tens`, `state-management`, `prospecting-qualifying`, `language-patterns`. `belfort.md` indexes them.
3. Read `OBJECTION-MATRIX.md` and `EMAIL-RULES.md`.
4. Read the relevant `APPLICATIONS/` file for the domain (federal-employees or gullstack-sales).
5. Draft. Self-audit against all three kings + WizGat + hard rules. Only output if every check passes.

## What this skill does not do

- Does not generate generic marketing copy.
- Does not promote without a named villain and an earned insight.
- Does not write from the company's perspective ("we help businesses…"). Rewrite from the hero's perspective.
