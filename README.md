# Three Kings Sales Talk Method

> Voss + Belfort + Miller. The unified communication doctrine behind Gull-Stack and Capital Wealth messaging.

Three communication masters. One integrated method. Every email, script, website, and conversation follows all three simultaneously.

## The Three Kings

| King | Framework | Core technique |
|---|---|---|
| **Chris Voss** | Never Split the Difference | Tactical empathy — mirror, label, accusation audit, no-oriented questions |
| **Jordan Belfort** | Straight Line System | Three Tens (product / company / you), tonality, looping objections, state control |
| **Donald Miller** | StoryBrand | Customer = hero, you = guide, name the villain |

And one principle that ties them together:

> **WizGat** — "What's So Great About That." Tie every fact to an emotional outcome. Features don't sell; the feeling sells.

## When to use

Every outbound message. Every landing page. Every call. Every bot's system prompt. If it is communication aimed at moving a buyer, it runs through the Three Kings.

## Structure

- `FRAMEWORKS/` — deep dive on each of the three + WizGat
- `APPLICATIONS/` — domain playbooks (federal employees, Gull-Stack sales)
- `OBJECTION-MATRIX.md` — per-framework responses to common objections
- `EMAIL-RULES.md` — hard rules (no "I", no questions, directive close)
